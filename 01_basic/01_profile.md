## Конфигурирование

Для управления S3-совместимым хранилищем необходимо настроить клиент, который будет выполнять запросы к API. В лабораторной работе используется AWS CLI — официальная утилита командной строки для работы с Amazon S3 и совместимыми сервисами, такими как MinIO.

### Настройка выполняется командой:

```bash
aws configure --profile minio
```
Будет предложено указать параметры подключения:

```
AWS Access Key ID: admin
AWS Secret Access Key: admin12345
Default region name: us-east-1
Default output format: json
```

Назначение параметров
AWS Access Key ID - Идентификатор пользователя (аналог логина). Используется при аутентификации запросов.
AWS Secret Access Key - Секретный ключ (аналог пароля), который используется для цифровой подписи каждого запроса.
Default region - Регион, в котором предполагается работать с хранилищем. Для локального MinIO обычно используется us-east-1 для совместимости с API Amazon S3.
Output format - Формат вывода результатов (json, table, yaml, text).

Параметры сохраняются локально в каталог пользователя:

~/.aws/credentials
~/.aws/config

Например:

```
[minio]
aws_access_key_id = admin
aws_secret_access_key = admin12345
```

При выполнении команд AWS CLI автоматически считывает эти параметры и использует их для подписи запросов.
